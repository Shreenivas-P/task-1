# Automated File Organizer

## About

A simple Python project that automatically organizes files into folders based on their file extensions.

## Features

* Organizes files automatically
* Creates folders for different file types
* Supports Documents, Images and Python files
* Places unknown files in the `Other` folder

## Technologies

* Python
* OS module
* Shutil module

## How to Run

```bash
python file_organizer.py
```

Enter the folder path when asked.

## Example

**Before:**

```text
notes.txt
photo.jpg
program.py
```

**After:**

```text
Documents/
Images/
Python_Code/
```
